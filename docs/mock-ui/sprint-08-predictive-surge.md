# Mock UI PRD — Sprint 8: Predictive Crowd Surge & Event Simulation

**Sprint reference:** `docs/sprints/sprint-08-predictive-surge.md`

## Purpose

Demonstrate the platform's forward-looking intelligence: 48-hour VCI forecasts driven by
train schedules and events, plus a "What-If" scenario builder that lets operators poke the
future — no ML backend required.

## Demo Surfaces

### 1. Predictive Surge Layer (`/dashboard` — new layer + `/predict` panel)
- Toggle: **"48h Forecast"** in Active Spatial Layers — renders projected VCI colors on
  exit zones (dashed/stippled style to distinguish from live)
- Forecast curves panel: per-station 48h line charts with live-now markers and
  predicted peaks; confidence band shading (fixture ± range)

### 2. Event Calendar & Timeline
- Upcoming events list: "GBK Concert — Fri 21:00 (projected VCI 92 at Senayan MRT)",
  "Holiday Exodus — Eid +2" — each with a confidence score and source chip (GTFS / Event feed)
- Selecting an event highlights affected exits on the map

### 3. What-If Scenario Builder
- Query builder UI: pick variables — train delay (+20 min), event end time (21:00),
  weather (rain), holiday multiplier — from seeded controls
- "Run Simulation" → animated recompute: forecast curves morph over ~3s to the scenario
  outcome; delta chips (`+18 VCI at Exit 3`)
- Scenario presets: "Train delay + concert ends 21:00", "Rain + Eid eve", "Normal Tuesday"

### 4. Early Warning Dispatch
- When a scenario (or baseline forecast) predicts VCI ≥ 80 within 24h: a "Predicted Surge"
  card appears with an **Advance Notification** action (simulated 24h-ahead dispatch to
  station masters, shown in the Command Center ticker — Sprint 7 hook)

## Mock Data

- 48h forecast series per exit (96 hourly points × confidence bands) generated by a
  deterministic fixture model (schedule + event multiplier + weather + noise)
- 6 events (3 concerts, 1 holiday, 2 GTFS schedule changes)
- Scenario mutation rules encoded as simple fixture math — no real ML

## Liveness Simulation

- Hourly forecast ticks forward every ~15s (live marker advances); the near-term window
  converges toward the live VCI from Sprint 3
- A forecast crossing 80 mid-demo auto-raises the Predicted Surge card

## Interactions

- Layer toggle, event selection, scenario variable controls, Run Simulation, presets
- Curve hover with tooltips; delta chip animations

## Demo Script

1. Open `/dashboard`, enable 48h Forecast — projected peaks visible as stippled zones
2. Open the forecast curves panel — Friday 21:00 peak flagged with confidence band
3. Click GBK Concert event — Senayan exits highlight on the map
4. Run What-If: "Train delay + concert ends 21:00" — curves morph, Exit 3 delta +18
5. Predicted Surge card appears; trigger Advance Notification → ticker event on Command Center

**Acceptance:** forecasts and scenario outcomes derive from the deterministic fixture model;
no ML service calls; demo badge visible.

## Dependencies

- Mock repository: `forecast-repository`
- Live driver: `forecast_tick`, `forecast_threshold_crossed`
- Shared fixture: VCI history (Sprint 3), event calendar, weather (Sprint 5)
- Shared components: chart utilities, alert banner, command center ticker hook
